# 素子コレクト - Maeda Jrs.

このリポジトリは、2026年8月1日〜3日に開催されたHacKitというハッカソンイベントの、チームMaeda Jrs.のリポジトリです。

## 概要

素子が戦うRPGゲーム

捕獲機能や合成機能(回路の組み合わせ)で素子を仲間にしていく

合成機能や図鑑機能を通して素子の性質を学ぶことができる

## プレイ画面

- 画像いくつか

## 背景・課題

母校の工業高校で電気回路が分からない人が続出

電気回路を楽しく学べるRPGを作って成績の向上を狙う

## 主な機能

・マップ機能 - 
 - **移動**：`WASD` または `←↑↓→`
- **決定**：`Space`
- **メニュー**：`M`
- **閉じる**：`Esc`
- **1つ戻る**：`Backspace`
              
・捕獲機能 - 野生の素子を捕まえることができる

・合成機能 - 素子同士を組み合わせて新しい素子や回路を作ることができる

・図鑑機能 - 素子の説明を見ることができる

## 工夫した点・こだわった点

合成機能のレシピを実際の回路に基づいて作った点

既存のBGMではなく１からBGMを作った点

## 使用技術

・pygame - ゲームのコア機能の実装用

・SQLite3 - キャラクターなどの管理用
